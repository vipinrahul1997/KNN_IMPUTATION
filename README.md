KNN Imputation (K-Nearest Neighbors Imputation) is a technique used to fill missing values by
looking at similar observations (neighbors) in the dataset.

Important: Scaling
Because KNN uses distance, features with large numerical ranges can dominate.

KNN Imputation fills missing values by finding the K most similar observations and using their available values to estimate the missing value.

Mean → Overall average

Median → Middle value

Mode → Most frequent category

KNN → Find similar rows and use their values
